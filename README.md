# Додо Пицца × Помощь приютам — лендинг

Промо-страница: хвостики из приютов, адреса приютов на карте, запись на прогулку.
Боевой адрес: `https://dodopizza.ru/pets` (город выбирается параметром `?city=`).
Прототип в студии: https://flowerdog-studio.github.io/dodo-priuty-proto/

Сайт полностью статический: без сервера, базы, npm и сборщиков. Чтобы выкатить, достаточно отдать файлы.

**Содержание:** [что в репозитории](#что-в-репозитории) · [выкладка](#выкладка-на-dodopizzarupets) · [параметры в адресе](#параметры-в-адресе) · [данные](#данные-где-что-лежит) · [частые задачи](#частые-задачи--рецепты) · [чек-лист состояний](#состояния-страницы--чек-лист) · [Яндекс Карты](#яндекс-карты-и-реклама) · [перед запуском](#перед-запуском)

## Выкладка на dodopizza.ru/pets

На сервер нужны только **`index.html`, `cookies.html` и папка `assets/`**. Все пути относительные (`assets/…`, `cookies.html`, `./`), поэтому сайт работает из любой папки, в том числе `/pets/`.

1. **Вариант А.** Положить `index.html`, `cookies.html` и `assets/` в папку, которая отдаётся по `/pets/`.
2. **Вариант Б.** Проксировать `/pets/` на любой статический хостинг с этими файлами.

**Слэш на конце.** Нужен редирект `/pets` → `/pets/` с сохранением query (`/pets?city=kazan` → `/pets/?city=kazan`). В `<head>` есть страховка: если страница открыта без слэша, скрипт ставит `<base href="/pets/">`. Но без редиректа браузер успевает сделать несколько лишних запросов в корень домена.

```nginx
location = /pets { return 301 /pets/$is_args$args; }

# кэш: картинки и шрифты надолго, страницу — коротко, чтобы правки данных доходили сразу
location /pets/assets/ { expires 30d; add_header Cache-Control "public"; }
location ~ ^/pets/(index|cookies)\.html$ { add_header Cache-Control "no-cache"; }
```

Если заменили фото, не меняя имени файла, у части посетителей может остаться старое из кэша. Надёжнее положить фото под новым `id` (см. [рецепты](#частые-задачи--рецепты)).

**Внешние зависимости — только Яндекс Карты** (`api-maps.yandex.ru` или `yandex.ru/map-widget`). Шрифты лежат локально, Google Fonts не используется.

**Cookies.** Внизу экрана при первом заходе — плашка: короткий текст, ссылка на `cookies.html` и кнопка «хорошо». После нажатия она больше не показывается: согласие хранится в `localStorage` под ключом `ck_ok`. Код в `src/template.html` — поиск по `ck_ok`. Если на dodopizza.ru уже есть общая плашка и политика, эту можно убрать: блок `#ck`, стили `.ck`, скрипт с `ck_ok`, ссылку в подвале и `cookies.html`.

**Аналитика.** Счётчиков нет. Код Метрики вставляется перед `</head>` в `src/template.html`, затем сборка.

**Вес.** `index.html` ~190 КБ (вместе с данными и шрифтом Dodo). Фото хвостиков ~50 КБ, грузятся лениво. Кадры анимации первого экрана подгружаются по мере прокрутки.

## Параметры в адресе

| Параметр | Что делает | Пример |
|---|---|---|
| `city` | Открывает страницу на нужном городе: шапка, карусель, карта, список приютов. При смене города адрес обновляется сам (без перезагрузки). Неизвестный или пустой → город по умолчанию | `/pets/?city=kazan` |
| `home` | Предпросмотр плашки «уже дома» на одном хвостике, без правок кода | `/pets/?city=peterburg&home=jek` |
| `soon` | Предпросмотр города-заглушки: текущий город показывается так, будто данных ещё нет | `/pets/?city=omsk&soon=1` |

Коды городов (поле `slug` в `CITIES`):

| Код | Город | Приют |
|---|---|---|
| `peterburg` | Санкт-Петербург (по умолчанию) | «Преданное сердце» |
| `moscow` | Москва | фонд «Рэй» |
| `kazan` | Казань | «Добрая лапа» |
| `krasnodar` | Краснодар | «Краснодог» |
| `omsk` | Омск | «Омские хвостики» |
| `stavropol` | Ставрополь | «Лучший друг» |
| `khabarovsk` | Хабаровск | «Добрый пёс» |
| `chelyabinsk` | Челябинск | «Того» |

Город по умолчанию — `DEFAULT_CITY` в `src/template.html`. В выпадающем списке города сортируются по алфавиту автоматически.

## Данные: где что лежит

Всё в `src/template.html`, в блоке `<script>`. Ищите по названию константы.

| Константа | Что в ней |
|---|---|
| `CITIES` | города и их приюты |
| `PETS` | хвостики |
| `SHOW_NO_TEXT` | показывать ли хвостиков без текста (сейчас `false`) |
| `HOME`, `HOME_ON` | кто уже дома |
| `DEFAULT_CITY` | город по умолчанию |
| `YMAPS_KEY` | ключ Яндекс Карт |
| `FAQ` | вопросы и ответы |

### Город — `CITIES`

```js
{slug:'omsk', name:'Омск', in:'в Омске', c:[54.9885,73.3242], z:11, list:[ /* приюты */ ]}
```

- `slug` — код для `?city=`;
- `name` — как в выпадающем списке;
- `in` — предложный падеж для фраз «хвостики в Омске…»;
- `c` и `z` — центр и зум карты (когда приютов несколько, карта сама охватывает все метки).

### Приют — элемент `list`

```js
{id:'togo', exact:1, n:'Приют «Того»', a:'Челябинск, ул. …', note:'уточнение к адресу',
 h:'Сб–вс 11:00–15:00', book:'Как записаться', rules:'Правила посещения',
 t:'+79517768004',
 ph:[['Елена, запись на визит','+79517768004'],['Мария','+79068606667']],
 msg:[['wa','WhatsApp','https://wa.me/7…'],['tg','Telegram','https://t.me/…']],
 mail:'priuttogo@gmail.com',
 links:{site:'https://…', vk:'https://vk.ru/…', tg:'https://t.me/…', ok:'…', dzen:'…', rutube:'…'},
 p:[55.1, 61.4]}
```

| Поле | Что это | Обязательно |
|---|---|---|
| `id` | код приюта, на него ссылаются хвостики | да |
| `n`, `a` | название и адрес | да |
| `p` | `[широта, долгота]` метки на карте. Удобно брать в Яндекс Картах: правый клик → «Что здесь?» | да |
| `t` | телефон для кнопки «связаться» на устройствах без JS | да |
| `exact` | `1` — адрес точный, ссылка «маршрут» строится по адресу; без него — по координатам `p` | нет |
| `note` | уточнение к адресу (например, «точка на карте условная») | нет |
| `h`, `book`, `rules` | часы, как записаться, правила — в карточке приюта, раскрываются по нажатию | нет |
| `ph` | телефоны `[подпись, номер]` в окне «связаться» | нет |
| `msg` | мессенджеры `[значок wa/tg, подпись, ссылка]` | нет |
| `mail` | почта | нет |
| `links` | сайт и соцсети, выводятся только заданные ключи | нет |

**Окно «связаться с приютом»** открывается кнопками «связаться», «погулять» и «поиграть». Главная оранжевая кнопка ведёт на сайт, если он есть, иначе во ВКонтакте, иначе в Telegram. Ниже — телефоны, мессенджеры, почта и чипы остальных соцсетей. Закрывается крестиком, кликом по фону и Esc.

**Instagram и Facebook** намеренно не выводятся: в РФ это продукты Meta, их упоминание требует маркировки.

### Хвостик — строка `PETS`

```js
['jek', 'dog', 'Джек', 'мальчик, 2 года', 'Цитата от лица хвостика', 'ps'],
// id    вид    кличка  пол и возраст      текст                     id приюта
```

- **id** — латиницей, уникальный. По нему ищется фото `assets/pets/<id>.webp`.
- **Вид** — `dog` или `cat`. От него зависят кнопка («погулять» / «поиграть»), стикеры и фильтр «собаки / кошки». Фильтр сам прячется, если в городе только один вид.
- **Пол и возраст** — формат «мальчик, 2 года» / «девочка, около 3 лет». Пустая строка — строка на карточке не выводится.
- **Текст** — от первого лица, без точки в конце, тире «—». Пустая строка — хвостик **скрыт** (пока `SHOW_NO_TEXT=false`).
- Порядок строк — порядок в карусели. Хвостики «уже дома» автоматически уезжают в конец.
- Предлоги и короткие слова сами привязываются к следующему слову, переносы в тексте ставить не нужно.

**Фото:** 600×861 px (вертикаль ≈ 0,7), webp, качество ~80, до 80 КБ. Морда в верхней половине кадра, по центру.

## Частые задачи — рецепты

После любого пункта: `python3 src/build.py`, проверить, выложить `index.html` (и новые файлы из `assets/`).

### Добавить хвостика
1. Подготовить фото 600×861 webp и положить в `assets/pets/<id>.webp`.
2. Добавить строку в `PETS` с `id` приюта из `CITIES`.

### Хвостик есть, а текста ещё нет
Добавьте строку с пустым текстом (`''`). Пока `SHOW_NO_TEXT=false`, карточка на сайте не видна. Как только впишете текст, она появится.
Если поставить `SHOW_NO_TEXT=true`, такие хвостики будут видны: только фото, кличка и приют.

Сейчас без текста (скрыты): Челябинск — Джуна, Оскар, Спирит; Петербург — Анфиса, Дина, Аргон; Казань — Лис; Москва — Бублик; Ставрополь — Людвиг, Милка Капри, Мельник, Рональд, Рябушка; Хабаровск — Астра, Белый, Леди, Потап, Аля, Афина, Оди, Санчо, Белочка, Серый.

### Фото ещё нет
Дайте хвостику `id`, начинающийся с `tbd-` (например, `tbd-rex`). Вместо фото появится плашка «фото скоро появится». Когда фото придёт, смените `id` на настоящий и положите файл.

### Хвостика забрали домой — плашка «уже дома»
Анкета **остаётся** на сайте. Добавьте `id` в `HOME`:

```js
const HOME=['jek','moti'];   // id хвостиков, которых забрали домой
```

Что меняется: фото приглушено, на нём плашка «уже дома», кнопки «погулять/поиграть» нет, карточка уезжает в конец карусели.
Посмотреть без правок кода: `?city=peterburg&home=jek`. `HOME_ON=false` выключает статус целиком.

### Убрать хвостика совсем
Удалите строку из `PETS` и файл фото. Если в городе не останется ни одной видимой анкеты, блок «о хвостиках» сам станет заглушкой «появятся совсем скоро».

### Добавить приют в существующий город
Добавьте объект в `list` города (поля — [выше](#приют--элемент-list)). Метка на карте, карточка приюта и окно «связаться» появятся сами.

### Добавить город
1. Добавьте объект в `CITIES`: `slug`, `name`, `in`, `c`, `z`, `list:[]`.
2. Пока `list` пустой и хвостиков нет, город работает как **заглушка**: «хвостики в … появятся совсем скоро» с кнопкой «выбрать другой город», «приюты в … скоро появятся» и карта, центрированная на городе. Ссылка `?city=<slug>` работает сразу.
3. Когда придут данные — добавьте приюты в `list` и хвостиков в `PETS`. Больше ничего менять не надо.

Посмотреть заглушку на любом городе: `?city=omsk&soon=1`.

### Убрать город
Удалите его объект из `CITIES` и строки его хвостиков из `PETS`. Ссылка `?city=` с этим кодом откроет город по умолчанию.

## Яндекс Карты и реклама

`YMAPS_KEY` в `src/template.html` — ключ JavaScript API Яндекс Карт.

- **Ключ пустой** (сейчас). Карта — бесплатный виджет `yandex.ru/map-widget`: стандартные метки, **может показывать рекламный баннер**.
- **Ключ задан.** Карта рисуется через JS API 2.1 с фирменными оранжевыми метками.

Чтобы рекламы не было нигде, нужен **платный тариф JavaScript API «Базовый (без рекламы)»** в кабинете разработчика Яндекса, на аккаунте Додо. В настройках ключа ограничьте домен `dodopizza.ru`. Наличие баннера зависит от того, есть ли у Яндекса реклама для конкретного зрителя, поэтому без ключа он может появляться не у всех.

## Прочее

- **Шрифты.** Dodo Narrow — собственность Додо, вшит в страницу при сборке (woff2, base64). Inter — локальные файлы в `assets/fonts/` (лицензия SIL OFL, `Inter-LICENSE.txt`), кириллица и латиница, начертания 500/600/700/800/900.
- **Анимация первого экрана** — покадровая (`assets/walk/`, десктоп `dNN.webp`, мобайл `mNN.webp`), привязана к прокрутке. При `prefers-reduced-motion` отключается.
- **Если картинка не догрузилась** (сбой сети), страница один раз сама пробует загрузить её заново.

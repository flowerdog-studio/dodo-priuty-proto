# Додо Пицца × Помощь приютам — лендинг

Промо-страница: хвостики из приютов, адреса приютов на карте, запись на прогулку.
Боевой адрес: `https://dodopizza.ru/pets` (город выбирается параметром `?city=`).
Прототип в студии: https://flowerdog-studio.github.io/dodo-priuty-proto/

Сайт полностью статический: без сервера, базы и сборщиков. Чтобы выкатить, достаточно отдать файлы.

---

## Что в репозитории

| Путь | Что это |
|---|---|
| `index.html` | **Готовая страница.** Собирается из `src/template.html`, руками не править |
| `cookies.html` | Готовая страница «Политика использования файлов cookies». Собирается из `src/cookies.html` |
| `assets/` | Картинки: иллюстрации, фото хвостиков (`assets/pets/`), кадры анимации (`assets/walk/`), стикеры, логотип |
| `src/template.html` | **Исходник главной**: разметка, стили, скрипты и все данные (города, приюты, хвостики, FAQ) |
| `src/cookies.html` | Исходник страницы cookies |
| `src/build.py` | Сборка: вшивает шрифт Dodo Narrow, пишет `index.html` и `cookies.html` |
| `backup-2026-11-13/` | Замороженная ранняя версия для студии. **На прод не переносить** |

### Как собрать

```
python3 src/build.py
```

Нужен только Python 3, без зависимостей. После сборки коммитить и `src/`, и готовые `index.html` / `cookies.html`.

## Выкладка на dodopizza.ru/pets

Все пути в страницах **относительные** (`assets/…`, `cookies.html`, `./`). Поэтому сайт работает из любой папки, в том числе `/pets/`.

1. **Вариант А.** Положить содержимое репозитория (кроме `src/`, `backup-2026-11-13/`, `README.md`) в папку, которая отдаётся по `/pets/`.
2. **Вариант Б.** Проксировать `/pets/` на любой статический хостинг с этими файлами.

**Важно: слэш на конце.** Нужен редирект `/pets` → `/pets/` с сохранением query (`/pets?city=kazan` → `/pets/?city=kazan`). На всякий случай в `<head>` уже есть страховка: если страница открыта без слэша, скрипт ставит `<base href="/pets/">`. Без редиректа браузер всё равно успевает сделать несколько лишних запросов в корень домена и получить 404. Пример для nginx:

```nginx
location = /pets { return 301 /pets/$is_args$args; }
```

Внешние зависимости:
- шрифт Inter с Google Fonts;
- Яндекс Карты (`api-maps.yandex.ru` или `yandex.ru/map-widget`).

Счётчиков аналитики пока нет. Если нужна Метрика, её код вставляется перед `</head>` в `src/template.html`, затем пересборка.

## Параметры в адресе

| Параметр | Что делает | Пример |
|---|---|---|
| `city` | Открывает страницу сразу на нужном городе: шапка, карусель хвостиков, карта и список приютов. При смене города на странице адрес обновляется сам (без перезагрузки). Неизвестный или пустой город → Санкт-Петербург | `/pets?city=kazan` |
| `home` | Предпросмотр статуса «уже дома» для одного хвостика, без правок кода | `/pets?city=peterburg&home=jek` |

Коды городов (поле `slug` в `CITIES`):

| Код | Город | Статус |
|---|---|---|
| `peterburg` | Санкт-Петербург | есть данные, город по умолчанию |
| `chelyabinsk` | Челябинск | есть данные |
| `krasnodar` | Краснодар | есть данные |
| `moscow` | Москва | заглушка |
| `kazan` | Казань | заглушка |
| `omsk` | Омск | заглушка |
| `stavropol` | Ставрополь | заглушка |
| `khabarovsk` | Хабаровск | заглушка |

Город по умолчанию задаётся в `DEFAULT_CITY` в `src/template.html`.

## Данные: где что лежит

Всё в `src/template.html`, в блоке `<script>`, поиск по названию константы.

### Города и приюты — `CITIES`

```js
{slug:'omsk', name:'Омск', in:'в Омске', c:[54.9885,73.3242], z:11, list:[ /* приюты */ ]}
```

Поля города:
- `slug` — код для `?city=`;
- `name` — как в выпадающем списке;
- `in` — предложный падеж для фраз «хвостики в Омске…»;
- `c` и `z` — центр и зум карты.

Приют в `list`:

```js
{id:'togo', n:'Приют «Того»', a:'адрес', h:'часы посещения', t:'+79517768004',
 l:{site:'https://…', vk:'https://vk.com/…', tg:'https://t.me/…'}, p:[широта, долгота]}
```

- `t` — телефон, всегда первая строка в окне «связаться с приютом».
- `l` — сайт и соцсети. Показываются только те ключи, что заданы; можно любой набор или вообще без `l`. Ссылка `'#'` выводится как «ссылка появится позже». **Сейчас у всех приютов стоят заглушки `'#'`**: заменить на реальные ссылки или удалить ключ.
- Координаты удобно брать в Яндекс Картах или 2ГИС.

Города в выпадающем списке сортируются по алфавиту автоматически.

### Хвостики — `PETS`

```js
['jek','dog','Джек','мальчик, 2 года','Цитата от лица хвостика','ps']
//  id   вид   кличка  пол и возраст     описание                  id приюта
```

- **Вид**: `dog` или `cat`. От него зависят кнопка («погулять» / «поиграть»), стикеры и фильтр «собаки / кошки». Фильтр сам прячется, если в городе только один вид.
- **Фото**: `assets/pets/<id>.webp`, 600×861 px (вертикаль ~2:3), webp. Морда в верхней трети кадра.
- Порядок в массиве — порядок в карусели.

### Город-заглушка (данных ещё нет)

Если у города `list:[]` и в `PETS` нет его хвостиков, страница показывает:
- в блоке «о хвостиках» — «хвостики в Омске появятся совсем скоро» и кнопку «выбрать другой город»;
- в «адресах приютов» — карточку «приюты в Омске скоро появятся» и карту, центрированную на городе.

Когда придут данные, нужно добавить приюты в `list` города и хвостиков в `PETS` с id этих приютов. Больше ничего менять не надо.

Чтобы убрать город из списка совсем, удалите его строку из `CITIES`. Ссылка `?city=` с этим кодом откроет город по умолчанию.

### Приют: поля и окно «связаться»

У каждого приюта в `CITIES` есть поля: `n` (название), `a` (адрес), `note` (уточнение к адресу), `h` (часы), `book` (как записаться), `rules` (правила), `t` (главный телефон), `ph` (все телефоны), `msg` (WhatsApp/Telegram для переписки), `mail`, `links` (`site`, `vk`, `tg`, `ok`, `dzen`, `rutube`).

- Карточка приюта: название, адрес, часы. «Как записаться и правила» раскрываются по нажатию.
- Окно «связаться с приютом» открывается кнопками «связаться», «погулять» и «поиграть». Главная оранжевая кнопка ведёт на сайт, если он есть, иначе во ВКонтакте, иначе в Telegram. Ниже — все телефоны, мессенджеры, почта и чипы остальных соцсетей.
- Instagram и Facebook намеренно не выводятся: в РФ это продукты Meta, их упоминание требует маркировки.

### Карточки-заглушки

Если `id` хвостика начинается с `tbd-` (например, Омск: `tbd-omsk1…15`), вместо фото показывается плашка «фото скоро появится», а вместо текста — «Информация скоро появится». Чтобы заменить заглушку, задайте настоящий `id`, положите фото в `assets/pets/<id>.webp` и впишите кличку, вид, возраст и текст.

## Хвостика приютили

Анкета **остаётся** на сайте, на ней появляется плашка «уже дома». Чтобы её включить, добавьте id хвостика в `HOME` (в `src/template.html`) и пересоберите страницу:

```js
const HOME=['jek','moti'];   // id хвостиков, которых забрали домой
```

Что меняется в карточке:
- фото слегка приглушено, на нём плашка «уже дома»;
- кнопки «погулять/поиграть» нет;
- карточка уезжает в конец карусели, чтобы первыми были те, кто ещё ждёт.

Посмотреть, как это выглядит, не меняя код: `?city=peterburg&home=jek`.

`HOME_ON=false` выключает статус целиком: все хвостики показываются как обычно, список `HOME` игнорируется.

Если хвостика нужно убрать с сайта совсем, удалите его строку из `PETS`. Когда в городе не останется ни одной анкеты, город автоматически станет заглушкой «скоро появятся».

## Плашка cookies

Внизу экрана при первом заходе: короткий текст, ссылка на `cookies.html` и кнопка «хорошо». После нажатия она больше не показывается: согласие хранится в `localStorage` под ключом `ck_ok`. Код в `src/template.html` — поиск по `ck_ok`. Если у dodopizza.ru уже есть своя общая плашка cookies, эту можно удалить: блок `#ck`, его стили `.ck` и скрипт.

## Счётчик корма

Блок перед FAQ: «собрали корма для хвостиков», N кг, полоска прогресса, цель. Одна цифра на все города.

Данные берутся из [Google Таблицы](https://docs.google.com/spreadsheets/d/1cNQ8JZBUp8-GQUuFfcN2F0sCOQDZbXmUVx6HpvxYzFA/edit) с доступом «все, у кого есть ссылка → читатель». Её можно редактировать.

| A | B |
|---|---|
| `собрано_кг` | сколько собрали |
| `цель_кг` | цель |

Обновление на сайте занимает до нескольких минут (Google кэширует).

В коде (`src/template.html`, поиск по `FOOD_`):
- `FOOD_URL` — откуда читать. Подходит CSV в том же виде (строки `собрано_кг` / `цель_кг`) или JSON `{"kg":1240,"goal":3000}`. Чтобы перейти на свой источник, например на админку dodopizza.ru, достаточно заменить этот адрес.
- `FOOD_FALLBACK` — что показать, если источник недоступен. Показывается также последнее удачно загруженное значение (хранится в браузере посетителя).

Сервисы Google из России работают нестабильно. Для прода лучше отдавать JSON со своего домена.

## Яндекс Карты и реклама

`YMAPS_KEY` в `src/template.html` — ключ JavaScript API Яндекс Карт.

- **Ключ пустой** (сейчас). Карта — бесплатный виджет `yandex.ru/map-widget`: стандартные метки, **может показывать рекламный баннер**.
- **Ключ задан.** Карта рисуется через JS API 2.1 с фирменными оранжевыми метками. Ключ также передаётся в виджет (`jsApiKey`).

Чтобы рекламы не было нигде, нужен **платный тариф JavaScript API «Базовый (без рекламы)»** в кабинете разработчика Яндекса, на аккаунте Додо. В настройках ключа ограничьте домен `dodopizza.ru`.

Наличие баннера зависит не от кода, а от того, есть ли у Яндекса реклама для зрителя. Поэтому в разных странах или регионах реклама может быть, а может не быть. На тарифе без рекламы баннера нет нигде.

## Прочее

- **Шрифт Dodo Narrow** — собственность Додо. Вшит в страницы при сборке (base64).
- **Типографика.** Предлоги и союзы автоматически привязываются к следующему слову (функция `nbsp`), длинные тексты выравниваются CSS `text-wrap`.
- **Анимация первого экрана** — покадровая (`assets/walk/`, 31 кадр: десктоп `dNN.webp`, мобайл `mNN.webp`), привязана к прокрутке. При `prefers-reduced-motion` отключается.
- **Открытые вопросы перед запуском:**
  - реальные ссылки на сайты и соцсети приютов (`l`);
  - данные городов-заглушек;
  - ключ Яндекс Карт;
  - счётчики аналитики;
  - превью для соцсетей (`og:image`, `og:description`) — пока не заданы.

# Додо × Помощь приютам — прототип лендинга

Живой прототип: открывается через GitHub Pages (ветка `main`, корень).

- `index.html` — собранная страница (не править руками)
- `src/template.html` — исходник: размеры в единицах макета `u(N)` = 1px кадра Figma (мобайл 390, десктоп 1495)
- `src/build.py` — сборка: `python3 src/build.py`
- `assets/` — иллюстрации, фото, стикеры

Шрифт Dodo Narrow — собственность Додо, используется только в прототипе.
